# Acceptance prompt: correction diffusion in a platform network

Synthetic acceptance scenario. Use a temporary workspace and no live platform writes.

## Prompt

Use `$communication-research-workflow`. Plan only.

Research topic: assess whether corrections and disputed claims follow different
diffusion patterns in a bounded public-conversation network.

Deliver:

1. the router classification and the exact descriptive, predictive, or causal claim;
2. node, edge, direction, cascade, time-window, deletion, bot, and missingness rules;
3. a validation plan for identifying corrections and disputed claims;
4. network measures, sensitivity checks, and explicit boundaries showing why
   centrality is not influence and diffusion is not persuasion.
