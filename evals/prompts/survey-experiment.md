Synthetic acceptance scenario. Use a temporary workspace and no real participant data.

## Prompt

Use `$communication-research-workflow`. Plan only.

Research topic: whether a source-transparency cue in a synthetic news interface changes
verification intention, and whether the effect depends on issue involvement.

Deliver:

1. the router classification (goal, archetype, specialist stack);
2. construct definitions and a measurement plan for transparency, verification

3. an experiment protocol covering conditions, held-constant features, manipulation
   pretest, power, exclusions, analysis, ethics, and preregistration;
4. the reviewer gates that would block fielding.

Do not create files outside a scratch output folder. Mark unsupported theoretical
relationships as hypotheses.
