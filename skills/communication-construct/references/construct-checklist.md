# Construct audit checklist

Use for large construct sets or contested discriminant boundaries.

## Search evidence

- [ ] Searched communication construct inventories and measurement reviews.
- [ ] Searched scale-development papers and appendices by concept, not only by label.
- [ ] Searched theory/review articles naming neighbors.
- [ ] Recorded search dates, databases, and failed synonym searches.

## Per proposed construct

- [ ] Exact label and all synonyms found in the literature.
- [ ] Canonical definition with citation and page/DOI where needed.
- [ ] Dimensions and whether they are formative or reflective.
- [ ] Closest neighbor and the discriminant boundary (one sentence).
- [ ] Where the boundary fails: what observation would make the two constructs indistinguishable.
- [ ] Measurement families consistent with the definition.

## Stability rules

- [ ] The definition-lock string is identical in theory, method, results, and discussion.
- [ ] No construct is renamed to match a result.
- [ ] No two constructs are defined as differently as their labels suggest but measured identically.
- [ ] Cross-field imports include an adaptation argument and a boundary condition.

## New-construct justification

Before marking `NEW-CONSTRUCT-JUSTIFIED`, all three must hold:

1. theoretical gap: existing constructs cannot express the mechanism or object;
2. distinct definition: differs from each neighbor on a specified dimension;
3. discriminant-validity plan: a design that could show the construct is not its neighbor.

If any item is missing, return the appropriate existing-construct verdict instead.
