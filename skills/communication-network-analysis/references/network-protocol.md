## Method-to-question map

| Question | Candidate method | Required evidence |
|---|---|---|
| Who occupies structurally distinct positions? | centrality, brokerage, core-periphery | mechanism linking position to the substantive role |
| Do ties cluster beyond specified baselines? | assortativity, community detection, null models | stability across algorithms/resolution and boundary choices |
| Which local processes are consistent with observed ties? | ERGM | convergence, degeneracy checks, goodness-of-fit, defensible terms |
| How do ties and attributes co-evolve? | SAOM/SIENA | at least suitable panel waves, rate assumptions, selection/influence specification |
| How do ordered interactions unfold? | relational-event model | event timestamps, risk set, actor availability |
| How does information spread? | cascade, hazard, diffusion, exposure-response | exposure opportunity, adoption event, temporal precedence |
| How do layers interact? | multilayer/multiplex models | layer-specific edge meanings; no unjustified projection |

## Minimum diagnostics

- node/edge counts before and after every filter;
- degree and component distributions, isolates, reciprocity, density, and temporal span;
- known-example tests for direction and weights;
- boundary, missingness, aggregation, threshold, and bot-rule sensitivity;
- model convergence and goodness-of-fit where applicable;
- uncertainty intervals or repeated-algorithm stability, not a single layout screenshot.

## Selection-versus-influence audit

Record whether similarity could arise from prior similarity, tie selection, common
exposure, institutional context, simultaneity, or measurement. Influence claims require
temporal order and a design that addresses those rivals; a longitudinal network model
is not automatically causal.
